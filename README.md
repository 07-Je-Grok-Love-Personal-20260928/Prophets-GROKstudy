## ✅ 引文规则

- 三大信经与三项联合信条：**逐字**取自 [ccifellowship.org](https://ccifellowship.org)。构建时会断言每一段引文都是原文的子串，发布后再用 `tools/verify_quotes.py` 核验一次。

- 经文：和合本。
