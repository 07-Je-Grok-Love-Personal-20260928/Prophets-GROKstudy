## 🆕 v2 更新说明（2026-11-14）

- **地图**：9 幅地图，每幅三种视图——① 离线 SVG 概念/情景图（带动画路线），② 地形图＋热点，③ 实时地图（自托管 Leaflet 1.9.4，12 个瓦片源：CARTO、Esri 地形/卫星、高德（中国大陆可用）、OSM、OpenTopoMap、HOT 等）。瓦片出错自动切换下一源；全部失败自动退回离线 SVG。中国时区默认先用高德。
- **流畅度**：去掉卡片与目录的 backdrop-filter（47→2 个元素）、`content-visibility:auto` 分段渲染、只用 transform 的漂浮云背景（滚动时暂停）、View Transitions 跨页过渡、Speculation Rules 预取＋悬停预取、Service Worker 离线缓存、图片懒加载，并遵循 prefers-reduced-motion。
- **内容**：每卷新增“本质一句话＋三根支柱”、历史深挖年表、古近东文化透视；史地页新增帝国动画、时间×听众矩阵、条约比较、被掳三世界。
- **笔记标记系统**（每页有图例）：粗体关键词、荧光底纹、实线/虚线/波浪下划线，以及 重点 / 难点 / 基督 / 圣约 / 应用 / 记忆 六类提示框；可一键切换“纯净阅读”和“挖空背诵”。
- **视频**：BibleProject 简体中文 20 部，点击才加载（youtube-nocookie），另备 MP4 直链，YouTube 不可用时也能看。
- **保留 v1 全部内容**：时间线、故事线、地理文化、圣经神学与圣约神学、可折叠目录、三大信经背诵版与深度对比、三项联合信条链接、速记工具。
- **质量**：引文逐字核验 0 处不符；Playwright 在 7 种宽度 × 16 页上点开全部交互，无溢出、无重叠、无 JS 错误、无坏链。

## ✅ 引文规则

- 三大信经与三项联合信条：**逐字**取自 [ccifellowship.org](https://ccifellowship.org)。构建时会断言每一段引文都是原文的子串，发布后再用 `tools/verify_quotes.py` 核验一次。
- 威斯敏斯特标准：只作转述，不作引号引用。
- 经文：和合本。
