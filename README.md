## 🆕 v3 更新说明（2026-11-14）

- **三级目录**：全站统一 `1 / 1.1 / 1.1.1` 编号（正文标题与目录一致）；每级可折叠，可一键“展开到一级/二级/三级”或全部展开/收起；滚动时高亮当前小节并点亮祖先路径、自动展开。
- **目录可拖宽**：拖动目录右边缘（鼠标、触屏、触笔都可，键盘 ←/→ 也可），宽度有上下限并自动记住；双击边缘恢复默认；长标题可切换“换行/单行”。手机上是可拉宽的抽屉。另有“全站 16 页”分组导航。
- **结构**：每卷书分为六部分——速览、处境、信息、神学、释读、应用；非逐卷页面也分成三个一级部分。
- **地图**：新增 **列国神谕图**（古实到以拦；赛13–23、耶46–51、结25–32、摩1–2）和 **下埃及图**（耶40–46），共 11 幅；每幅仍有离线 SVG 讲解图、地形图，以及 12 源实时地图（自动换源，全部失败退回 SVG）。
- **背诵**：每卷新增“一页背诵卡”；速记页新增十二个关键术语；首页新增十七卷篇幅柱状图；标记新增“框＝术语”“红实线＝审判/警告”“蓝双线＝应许”。
- **流畅度**：去掉最后的毛玻璃顶栏、漂浮动画层和滚动渐显；进度条改用 CSS 滚动驱动动画（不跑 JS）；滚动高亮只用 IntersectionObserver；非首屏交互在空闲时才初始化；手机目录关闭时跳过渲染。实测滚动期间渲染开销从 68–195 ms 降到 4–27 ms（390 px，CPU 4× 降速）。
- v1、v2 的全部内容与功能保留。

## ✅ 引文规则

- 三大信经与三项联合信条：**逐字**取自 [ccifellowship.org](https://ccifellowship.org)。构建时会断言每一段引文都是原文的子串，发布后再用 `tools/verify_quotes.py` 核验一次。
- 威斯敏斯特标准：只作转述，不作引号引用。
- 经文：和合本。

## 🛠️ 构建

```bash
cd build && python3 build.py          # 生成 docs/*.html
python3 ../tools/verify_quotes.py     # 逐字核验
python3 ../tools/qa3.py               # v3：7 种屏宽 × 16 页；点开全部交互，逐个折叠目录、拖宽到最小/最大、检查滚动高亮
```
